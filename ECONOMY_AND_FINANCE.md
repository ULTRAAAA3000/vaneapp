## 1. Основная Philosophy & Headless Vision

Vane — это сверхбыстрый, легкий (Cloudflare Edge) автопостинг, API-шлюз и движок управления контентом для соло-фаундеров, инди-хакеров, разработчиков, SMM-специалистов и видео-мейкеров.

### Ключевые отличия от устаревших гигантов (Buffer, Hootsuite, Later)
1. **Без «Налога на каналы»:** Фиксированная ставка за неограниченное количество подключенных аккаунтов и воркспейсов в UI.
2. **Instant Edge Publishing (0ms cold starts):** Выполнение задач секунда в секунду благодаря 300+ дата-центрам Cloudflare по всему миру.
3. **Headless & AI-Native First:** Нативная поддержка REST API, Make.com, Zapier, Custom GPT Actions и Claude MCP Server.
4. **Нативная поддержка Telegram & Видео:** Полная поддержка inline-кнопок, спойлеров, а также подготовка к загрузке Shorts/Reels/TikTok через R2.

## 2. Тарифная Сетка и Модель Монетизации

### 2.1. Free Trial ($0.00 / Onboarding)

- **Защита от абуза:** Ограничение по IP/Fingerprint, жесткая блокировка при исчерпании 30 постов без авто-списаний.

### 2.2. Pure Developer API Tier ($5.99 / мес) — *Headless Gateway*
- **Цель:** Захват разработчиков, инди-хакеров, скриптов, Custom GPT и Make/Zapier связок.

- **Что входит:**

  - **180 API-постов в месяц** (~6 постов/день).
  - Вход в экосистемы Custom GPT Store & Claude MCP Server.
- **Overage Rates (Тарификация превышения квоты):**
  - Обычный пост (текст/медиа): **$0.03 / пост**
  - AI-Generated пост (Workers AI synthesis + dispatch): **$0.09 / пост**

### 2.3. Vane AI Engine & AI Pass Mechanics

ИИ-функционал разделен на две категории для максимальной конверсии и оптимизации COGS:

1. **Free AI Utilities (Доступно на всех тарифах, включая Free Trial):**
   - **Hashtag Generator:** Авто-генерация хештегов по смыслу поста.
   - **Emoji Enhancer & Grammar Fix:** Базовая коррекция текста и эмодзи.
   - **Char Limit Guard:** Адаптация длины под ограничения сетей.
   - *Инфраструктура:* Легкие модели Workers AI, себестоимость ~$0.000001/запрос.

2. **Vane AI Pass (Включен в Pro Dashboard / $0.09 за AI-пост в API Tier):**
   - **Smart Re-formatter:** Авто-трансформация Telegram-лонгридов в треды для X/Threads и посты для LinkedIn.
   - **Full Post & Idea Generator:** Генерация постов с нуля и создание контент-планов.
   - **Tone Fixer:** Трансформация тона (Professional, Viral, Friendly, Tech).
   - **Hook & CTA Generator:** Создание виральных хуков и конверсионных призывов к действию.
   - **Video Script Generator (Phase 2):** Сценарии и хуки для YouTube Shorts, TikTok и Reels.
   - *Лимиты:* В Pro Dashboard входит мягкий лимит ~250 генераций/мес. В API Tier тарифицируется по **$0.09 / AI-пост**.

## 5. Платежная Инфраструктура и Эквайринг (Локальный & Международный контур до переезда)

С учетом текущего возраста (16 лет) и локации (Украина) исключаются зарубежные сервисы с заблокированным онбордингом (Lemon Squeezy) и сложная зарубежная бюрократия. Используется рабочая двухконтурная схема:

### 5.1. Контур А: Monobank Acquiring (International Mode)
- **Суть:** Включение поддержки международных Visa / Mastercard и Apple Pay / Google Pay в кабинете мерчанта Monobank.
- **Как работает для европейцев:** Покупатель из Германии или США вводит данные своей карты в EUR/USD или зажимает Apple Pay. Monobank списывает эквивалент в UAH по актуальному курсу (например, €12.00 ≈ 530 UAH), сам проводит трансграничную конвертацию и зачисляет деньги на украинский счет.
- **Плюсы:**
  1. **100% готовность из коробки:** Работает без заграничных юрлиц и проверок.
  2. **Мгновенный Webhook:** При успешном списании Monobank отправляет JSON-вебхук на наш Cloudflare Worker для активации подписки/генерации ключа `cpost_` или `cvid_`.
  3. **Apple Pay / Google Pay:** Высокая конверсия на мобильных устройствах.

### 5.2. Контур Б: Crypto Checkout (USDT / USDC на Solana / Polygon)
- **Суть:** Прямая Web3-оплата для инди-хакеров, разработчиков и крипто-сообществ, покупающих API-доступ.
- **Как работает:**
  1. Юзер выбирает план (например, Pure Developer API за $5.99).
  2. Frontend показывает QR-код с суммами и адресом Solana-кошелька Vane.
  3. Наш Cloudflare Worker под капотом слушает Solana RPC-узел (через Helius/QuickNode).
  4. При обнаружении транзакции с нужной суммой Worker за **0.5 секунд** активирует подписку в D1.
- **Плюсы:** 0% комиссий эквайринга, мгновенная выручка на личный кошелек (Phantom/Trust Wallet), полная автономия от банков.

### 5.3. Транзит в Европу (Перспектива: Австрия / 18 лет)
- При переезде в Клагенфурт и получении австрийского IBAN/ВНЖ за 15 минут активируется прямой аккаунт Stripe / Paddle.
- В коде бэкенда замена провайдера требует только обновления переменной окружения `PAYMENT_GATEWAY_KEY`.

## 6. API Key Scoping & Security Specification

Для изоляции доступов, безопасности и мгновенной валидации на Edge используется префиксная система API-ключей:

- **Text Post Engine Key:** `cpost_live_[16_char_hash]` (Доступ только к текстово-графическим эндпоинтам, проверяет квоту 180 API posts).
- **Video Engine Key:** `cvid_live_[16_char_hash]` (Доступ только к видео-эндпоинтам и R2 Chunked Uploads).
- **Test Mode Keys:** `cpost_test_...` / `cvid_test_...` (Эмуляция ответов без списывания квот и выполнения реальных запросов в соцсети).
- **Security Standard:** Ключи генерируются через `crypto.getRandomValues()`, хешируются по алгоритму SHA-256 и сохраняются в D1.

## 7. Дорожная Карта Реализации (Technical Roadmap)

### Phase 1: Core API & Text MVP (Сейчас)
1. **База данных D1:** Создание таблиц `users`, `api_keys`, `subscriptions`, `usage_logs`, `transactions`.
2. **Middleware безопасности:** Хеширование API-ключей (`cpost_live_...`) в D1, валидация заголовка `Authorization: Bearer <token>`, проверка активности подписки.
3. **Metered Engine:** Подсчет `monthly_usage_count` и автоматический возврат ошибки `402 Payment Required` при превышении лимитов.
4. **Workers AI Integration:** Вызовы `@cf/meta/llama-3.1-8b-instruct` для реформата и генерации тональности.
5. **Monobank & Crypto Webhook Workers:** Обработчики входящих транзакций и автовыдача ключей.
6. **Интеграции:** Telegram Bot API, X (Twitter) v2 API, LinkedIn API, Threads API.

### Phase 2: AI Ecosystem & No-Code (Сразу после MVP)
1. **OpenAI Custom GPT Action:** Публикация официального Vane GPT в GPT Store.
2. **Claude MCP Server:** Создание и регистрация Vane MCP Server в каталоге Anthropic.
3. **Make.com & Zapier:** Разработка и публикация модулей в каталогах интеграций.

### Phase 3: Vane Video Engine Expansion
1. **Бюрократический спринт:** Прохождение App Verification в Google Cloud Console (YouTube API), Meta Developer Portal (Instagram API) и TikTok Developer API.
2. **R2 Chunked Uploader:** Реализация ресурсоэффективной загрузки бинарных видеофайлов через Cloudflare R2.
