## 1. Основная философия и ценность продукта

Vane — это сверхбыстрый, легкий (на базе Cloudflare Edge) автопостинг и движок управления контентом, созданный для соло-фаундеров, инди-хакеров, SMM-специалистов и контент-мейкеров.

### Ключевые отличия от устаревших гигантов (Buffer, Hootsuite, Later)
1. **Без «Налога на каналы»:** Фиксированная ставка за неограниченное количество подключенных аккаунтов и воркспейсов вместо $6–$15 за каждый канал.
2. **Мгновенный автопостинг (Instant Edge Publishing, 0ms задержки):** Использование Cloudflare Workers, развернутых в 300+ дата-центрах по всему миру для выполнения задач секунда в секунду.
3. **Нативная поддержка Telegram первого класса:** Полная поддержка inline-кнопок с ссылками, скрытых спойлеров, тихих уведомлений, авто-закрепов и редактирования постов прямо из дашборда.
4. **API и вебхуки для разработчиков:** Нативные REST API эндпоинты и входящие вебхуки для автоматизации рабочих процессов (GitHub, Stripe, Make.com, n8n).

## 2. Тарифная сетка и архитектура цен

### 2.1. Бесплатный тариф (Free Tier / Онбординг)
* **Цель:** Вход без трения и без ввода банковской карты, чтобы юзер привязался к продукту и оценил скорость Edge.
* **Цена:** `$0.00 / мес` (карта не требуется).
* **Лимиты:**
  * До **2 подключенных каналов** (например, 1 Telegram-канал + 1 X-аккаунт).
  * До **10 запланированных постов в месяц** (или лимит в 5 постов в очереди одновременно).
  * **10 бесплатных ИИ-кредитов** (разовый триал для тестирования реформаттера и коррекции тона).
* **Себестоимость для нас:** **~$0.00000 / мес** (полностью перекрывается бесплатными лимитами Cloudflare).

### 2.2. Vane Pro (Основная подписка)
* **Цель:** Высокая конверсия за счет отказа от сложных таблиц с тарифами. Единый безлимитный доступ.
* **Цена:** **`$12.00 / мес`** ИЛИ **`$99.00 / год`** (экономия ~31% при оплате за год).
* **Что входит:**
  * **Безлимитные воркспейсы и каналы** (Telegram, X/Twitter, LinkedIn).
  * **Безлимитный отложенный постинг** (*Fair Use Policy: ~2,000 постов/мес на аккаунт*).
  * Нативные фишки Telegram (inline-кнопки, спойлеры, опросы).
  * Мульти-аккаунт матрица с превью лимита символов и авто-форматированием в реальном времени.
  * Встроенный UTM-конструктор и сокращатель ссылок.
  * Функция Auto-First-Comment (авто-комментарий при публикации) для X/Twitter и Telegram.
  * Интеграции через вебхуки и персональный API-ключ разработчика.
  * Медиа-библиотека на базе Cloudflare R2.

### 2.3. Vane AI Pass (ИИ-Дополнение)
* **Цель:** Максимизация LTV без вызова раздражения у пользователей (отказ от мелких списаний по $1–$2 за клик по каждой кнопке).
* **Цена:** **`+$3.50 / мес`** (при оплате за год) или **`+$4.99 / мес`** (при помесячной оплате).
* **Конверсионный сценарий:**
  1. Юзер получает 10 бесплатных ИИ-генераций внутри Vane Pro.
  2. На 11-й запрос появляется единое окно с предложением подключить **Vane AI Pass**.
  3. Никакой раздробленной оплаты за отдельные ИИ-фичи.
* **Что входит:**
  * **Smart Re-formatter:** Превращает лонгриды из Telegram в лаконичные треды для X/Twitter или посты для LinkedIn.
  * **Tone Fixer:** Регулировка тональности (профессиональная, виральная, дружеская, техническая).
  * **Hook Generator:** Генерация цепляющих первых строчек.
  * **Ideas Generator:** Идеи и темы для контент-плана.
* **Лимиты:** Мягкий лимит ~200 генераций/мес (Soft-limit через Cloudflare Workers AI для защиты маржи).

## 3. Финансовая механика и юнит-экономика

### 3.1. Структура затрат на одного пользователя (COGS)

#### Затраты на инфраструктуру (Cloudflare Stack)
* **Workers & Pages:** Первые 100,000 запросов в день БЕСПЛАТНО. Платный тариф ($5/мес) включает 10,000,000 запросов/мес + $0.30 за каждый дополнительный миллион.
* **D1 Database:** Первые 5 млн чтений / 100 тыс записей в день БЕСПЛАТНО.
* **R2 Media Storage:** Первые 10 ГБ БЕСПЛАТНО. Далее $0.015/ГБ.
* **Workers AI:** Лимит бесплатных нейронов (~10 тыс нейронов в день). При превышении стоимость составляет всего ~$0.00001 за одну текстовую генерацию.

#### Средняя себестоимость активного Pro-пользователя ($12/мес):
* Вычисления Cloudflare Edge и записи в БД: **~$0.002**
* Хранение картинок в R2 (примерно 50 МБ медиа): **~$0.001**
* **Итого себестоимость (Core Pro):** **~$0.003 / мес**
* **Валовая маржинальность (Core Pro):** **~99.97%**

#### Средняя себестоимость пользователя с AI Pass (+$3.50/мес):
* 150 ИИ-генераций через Cloudflare Workers AI / Groq API: **~$0.035**
* **Итого себестоимость (AI Pass):** **~$0.035 / мес**
* **Валовая маржинальность (AI Pass):** **~99.00%**

## 4. Платежная инфраструктура и стратегия эквайринга

С учетом возраста (16 лет) и юридического статуса (Украина -> транзит в Австрию) прием платежей реализуется через поэтапную гибридную схему.

+-------------------------------------------------------------------+

+---------------------------------+---------------------------------+
|
+---------------------+---------------------+
|                                           |
v                                           v
[КАРТЫ / APPLE PAY]                        [КРИПТО-ОПЛАТА]
(Visa, Mastercard)                         (USDT / USDC)
|                                           |
v                                           v
+-----------------------+                   +-----------------------+
|  Lemon Squeezy /      |                   | NOWPayments / Helio / |
|  Monobank Эквайринг   |                   | Свой Worker (Solana)  |
|  (Родительский аккаунт)                   | (Напрямую на кошелек) |
+-----------+-----------+                   +-----------+-----------+
|                                           |
+---------------------+---------------------+
|
v
[CLOUDFLARE WORKER WEBHOOK]
|
v
[ОБНОВЛЕНИЕ D1 DB: АКТИВАЦИЯ PRO]


### 4.1. Этап 1: Запуск MVP (16 лет, Украина)
1. **Крипто-платежи (100% автономно и напрямую):**
   * **Токены:** USDT / USDC (сети Solana и Polygon для минимальных комиссий в пару центов).
   * **Обработка:** NOWPayments / Helio API или собственный скрипт на Cloudflare Worker, проверяющий подписи транзакций в блокчейне.
   * **Целевая аудитория:** Web3-разработчики, крипто-сообщества, владельцы Telegram-каналов.
   * **Вывод:** Мгновенный приход средств на личный некостодиальный кошелек (Phantom/Trust Wallet).

2. **Оплата картами (Visa/Mastercard/Apple Pay):**
   * **Провайдер:** Lemon Squeezy / Paddle (оформленный через родителя / родительский ФОП).
   * **Интеграция:** Все API-ключи, вебхуки, логика базы D1, код и управление продуктом на 100% находятся у Фаундера.
   * **Вывод:** Автоматические выплаты на привязанный банковский IBAN.

3. **Ручные B2B-инвойсы (Годовые тарифы):**
   * Прямая выписка счетов по SEPA/IBAN для европейских B2B-клиентов при покупке годового Pro ($99/год).

### 4.2. Этап 2: Европейский транзит (ВНЖ в Австрии / 18 лет)
1. **Основной эквайринг:** Прямой аккаунт **Stripe / Lemon Squeezy**, зарегистрированный на европейский ID / студенческий ВНЖ (Vertriebenenkarte) в Клагенфурте, Австрия.
2. **Налоги:** Автоматический расчет НДС (VAT MOSS/OSS) берет на себя Lemon Squeezy / Paddle в роли Merchant of Record (MoR).
3. **Бесшовный переезд:** Код менять не нужно; достаточно обновить `STRIPE_SECRET_KEY` / `LEMON_SQUEEZY_API_KEY` в секретах Cloudflare.

## 5. Стратегия вывода на рынок (Go-To-Market)

### 5.1. Фаза первичного трафика (СНГ — Низкая стоимость привлечения)
* **Канал:** Прямой ручной аутрич администраторам Telegram-каналов, сеткам каналов и инди-креаторам.
* **Тактика:**
  * Предоставление расширенного 14-дневного триала Pro в обмен на обратную связь.
  * Демонстрация нативных фишек Telegram (inline-кнопки, спойлеры, быстрый постинг).
* **Главная цель:** Проверка стабильности продукта, получение первой выручки и сбор отзывов.

### 5.2. Фаза европейской экспансии (Tier-1 — Высокий LTV)
* **Каналы:** X/Twitter (хэштег #BuildInPublic), LinkedIn (B2B-фаундеры, рекрутеры, солопренеры).
* **Позиционирование:** *"The Unfairly Fast Scheduler for X, LinkedIn & Telegram. No per-channel tax."*
* **Ростовые хаки:**
  * Бесплатный доступ к API/вебхукам для инди-разработчиков, создающих свои автоматизации.
  * Страницы сравнения (*Vane vs Buffer*, *Vane vs Hootsuite*), бьющие по ключевым запросам цен.
