Integrations

Post from wherever you already work.

Ask an AI to schedule it, drop it into an automation, or publish from your CMS. Every connector below talks to the same Vane API, so your plan, quota and channels are the same everywhere.

● API access opens with launch. Join the waitlist to get early keys. Start with a cpost_test_… key: everything works, nothing is posted or counted.

ChatGPT

Soon

A Custom GPT that lists your channels, shows you the text, channels and time, waits for your “yes”, then schedules the post. No code. Coming soon.

Claude

Self-serve

Tell Claude “post this to Telegram and Bluesky tomorrow at 9:00”. A connector built on the Model Context Protocol gives it two tools: list your channels and create a post.

  1. Create a key in the dashboard.
  2. Add the Vane connector to Claude Desktop (or the remote endpoint /api/v1/mcp).
  3. Ask.

Zapier

Soon

An app with a Create post action and instant Post published and Post failed triggers, powered by Vane webhooks. Chain a new blog post, a Notion row or a form answer into a scheduled post.

Built and tested; it will appear in the Zapier directory once it is approved.

Make

Soon

A Make app with a connection by API key and modules to create a post, list channels and read a post’s status, plus an instant trigger for published and failed posts.

Built and tested; it joins the Make app directory after review.

WordPress

Self-serve

Vane for WordPress adds a small Vane dashboard to your admin menu: write a post, pick channels, post now or schedule, see the queue and history. It also cross-posts every new article from the editor sidebar.

Install it in two minutes → (the WordPress.org directory listing follows after review).

REST and webhooks

Self-serve

Anything that can make an HTTPS request can schedule a post, and anything that can receive one can hear about the result. Scripts, bots, CI jobs, your own back office.
