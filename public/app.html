Connect Claude

Post to your channels by talking to Claude: “post this to Telegram and Bluesky tomorrow at 9:00”. Claude adds Vane as a connector; you add it once, by hand, in Claude’s settings.

Connector address
https://vaneapp.dev/api/v1/mcp
  1. 1. Open Claude’s connectors. In Claude (web or desktop): Settings → Connectors → Add custom connector. Custom connectors need a Claude plan that allows them; if you do not see the button, check your Claude plan or ask your workspace admin.
  2. 2. Paste the address. Name it Vane, paste the address above, press Add.
  3. 3. Press Connect. A Vane page opens. Sign in and press Allow. No key to copy: Vane makes a key called “Claude connector” for you. Prefer a key you already have? Open “Use one of my own API keys instead” on that page and click it in the list (the ones used with Claude are on top): nothing to copy or type. Your keys are in API keys.
  4. 4. Try it. Ask Claude: “Show my Vane channels”, then “Post ‘Hello’ to Telegram in 5 minutes”. A test key says TEST MODE and posts nothing.

Commands

Vane gives Claude ready-made commands, so you do not have to explain what to do. In Claude (web or desktop) press + in the chat and choose Vane. To have them pop up as soon as you type /, add the Vane plugin below.

CommandWhat it does
postSchedules the text you give it, word for word. Optional: channels, time.
draftClaude writes the post from your topic, shows it, and schedules it only after you approve.
channelsLists the channels connected to Vane.
upcomingShows what is scheduled.

Commands in the / menu: the Vane plugin

The plugin brings the connector and the same commands as /vane:post, /vane:draft, /vane:channels, /vane:upcoming, /vane:recent, /vane:analyze and /vane:series. The last two need a paid plan. Type / and they appear in the list.

Good to know

  • Posts made through Claude count against your plan like any API post. Live posting needs a plan with API access; a test key is always free.

  • To disconnect, revoke the key “Claude connector” under API keys, or remove the connector in Claude.

Vane for WordPress

Vane inside your WordPress admin: write a post, pick the channels, post now or schedule it, and cross-post every new article the moment you publish it.

Plugin file

vane-for-wordpress.zip

Version 2.0 · WordPress 6.0+ and PHP 7.4+ · free

Download plugin (.zip)
  1. 1. Add the plugin. In WordPress open Plugins → Add New → Upload Plugin, choose the file you just downloaded, press Install Now, then Activate. Do not unzip it first.
  2. 2. Make a key. Create an API key under API keys and under Used with choose WordPress plugin. Start with a cpost_test_… key: it tries everything and posts nothing.
  3. 3. Connect. In the WordPress menu open Vane, paste the key and press Connect. Your plan and channels appear.
  4. 4. Post. On the Write tab type something, tick a channel and press Post now. When you are happy, swap to a cpost_live_… key under Settings.

What you get

  • Write: a post with the character limit of each network, an image from your Media Library, or one of your latest articles with its link.
  • Scheduled and history: see the queue and cancel a post before it goes out; see what was sent, with a link to the live post and the reason if it failed.
  • Vane Cross-Post: a panel in the editor sidebar. Pick channels and edit the text; it is sent once, when the article first goes live. Editing it later never posts again.

Good to know

  • Your key stays on your server; the browser never sees it. Only Editors and Administrators can post, only Administrators can connect the key.
  • Live posting needs a plan with API access; a test key is always free. Posts made from WordPress count against your plan like any API post.
  • To stop cross-posting: Vane → Settings untick Cross-post new articles, or switch it off for one article in the editor sidebar.
  • To disconnect, press Disconnect under Vane → Settings, then revoke the key under API keys. Deleting the plugin removes its settings.
  • More detail and screenshots on the WordPress plugin page.

Connect Notion

Publish from your Notion content calendar: tell a Notion agent “schedule every row marked Ready” and it posts through Vane, after you approve. Notion adds Vane as a custom MCP connection; you add it once, by hand, in Notion’s settings.

MCP server address
https://vaneapp.dev/api/v1/mcp
  1. 1. Allow custom connections. A Notion workspace admin opens Settings → Connections and turns on Enable custom MCP servers. Custom Agents are part of Notion’s Business and Enterprise plans; if you do not see the option, check your Notion plan or ask your workspace admin.
  2. 2. Add Vane to an agent. Open the Custom Agent, go to Settings → Add connection → Custom MCP server, name it Vane, paste the address above and press Connect. Notion shows a notice that it has not reviewed the server; that is shown for every custom server.
  3. 3. Press Allow. A Vane page opens. Sign in and press Allow. No key to copy: Vane makes a key called “Notion connector” for you. Your keys are in API keys.
  4. 4. Give the agent its rules. Paste the instructions below into the agent’s instructions, so it always shows you the post and waits for your yes.
  5. 5. Try it. Ask the agent: “Show my Vane channels”, then “Post ‘Hello’ to Telegram in 5 minutes”. A test key says TEST MODE and posts nothing.

Agent instructions

You are the Vane publisher for this workspace. You post to my social channels through the Vane connector.
1. Before the first post of a conversation, call vane_list_channels and use only the channels it returns.
2. When I point at a Notion page or a database row, post only the text I mean (the page body or its "Post text" property), never the whole page.
3. Always show me the final text, the channels and the time, and wait for my yes before you call vane_create_post. Never post by yourself or on a schedule of your own.
4. I write times in my local time. Send scheduled_at as an ISO 8601 time with its offset.
5. After posting, tell me what was scheduled and for when. If I asked, set that row's Status to "Scheduled".
6. If a tool answers with an error, show me its message and stop. Do not retry with changed text.

A content calendar that publishes

Make a Notion database with these properties, then let the agent read it:

PropertyTypeUsed for
Post textTextWhat goes out, word for word.
ChannelsMulti-selectTelegram, Bluesky, Mastodon… the agent matches them to your Vane channels.
Publish atDateWhen to post, in your time.
StatusStatusDraft → Ready → Scheduled. The agent only takes Ready rows and marks them Scheduled.

Then ask: “Schedule every row in Content calendar with Status Ready.” It shows each post and waits for your yes.

Good to know

  • Posts made through Notion count against your plan like any API post. Live posting needs a plan with API access (the Suite includes it); a test key is always free.
  • The agent only sees your channel names and your posts, never your passwords or channel credentials.
  • To disconnect, revoke the key “Notion connector” under API keys, or remove the connection in Notion.

Feeds

Follow a blog, a podcast or a news site (RSS or Atom). Each new item becomes a scheduled post on the channels you choose, a few minutes after it appears, so you can still cancel it. Items that are already in the feed are never posted.

Post to
Text of the post

Use {title}, {summary} and {link}. Too long for a network? The summary is shortened for you.

Wait before posting (minutes)

The feed is checked every 30 minutes. At most 3 new items are posted per check, and items older than 3 days are skipped, so a blog that was offline never floods your channels. The Free Trial follows 1 feed, paid plans up to 10. Posts count against your plan like any post made here.

Apple Shortcuts

Share a link, a selection or a note from any app on your iPhone, iPad or Mac to Vane. It becomes a scheduled post a few minutes ahead, so you can still cancel it.

Share address
https://vaneapp.dev/api/v1/share
  1. 1. Make a key. Under API keys create one and pick Apple Shortcuts in “Used with”. A test key (cpost_test_…) checks everything and posts nothing. A live key needs a plan with API access.
  2. 2. New shortcut. Open the Shortcuts app, press +, open the shortcut’s settings and turn on Show in Share Sheet (accept Text and URLs).
  3. 3. Add “Get Contents of URL”. URL: the share address above. Show More → Method POST. Headers: Authorization = Bearer + your key. Request Body: JSON, add a Text field text and put Shortcut Input in it.
  4. 4. Pick the channel. With one channel you can leave it out. With several, add a Text field channels with the channel’s name (for example Vane News) or the platform (telegram). Optional: delayMinutes (default 5).
  5. 5. Share. In any app press Share and choose your shortcut. Vane answers with the time it is scheduled for. To undo, cancel the post under Upcoming.

What you can send

FieldMeaning
text, url, titleJoined into one post. A link already inside the text is not added twice.
channelsNames, platforms or ids, as a list or separated by commas. Needed when you have several channels; the error lists them.
delayMinutes1 to 1440, default 5. Or send scheduledAt with a time.
mediaUrlA public picture link.

Prefer no JSON? Send the text as the plain request body and put the rest in the address: …/share?channels=Vane%20News&delay=10.

Vane for Obsidian

Post or schedule the open note, or just the selected text, to your channels without leaving Obsidian. Works on desktop and on the phone. Markdown is turned into plain post text, and you can edit it before sending.

Plugin
Download vane-for-obsidian.zip A folder called vane with three files.
  1. 1. Make a key. Under API keys create one and pick Obsidian plugin in “Used with”. A test key (cpost_test_…) checks everything and posts nothing, handy for a first try.
  2. 2. Install the plugin. Unzip it into <your vault>/.obsidian/plugins/ so you get .obsidian/plugins/vane/. In Obsidian: Settings → Community plugins → turn off Restricted mode, press the refresh icon, enable Vane. On a phone, copy the folder there with your file app or your sync tool.
  3. 3. Paste the key. Settings → Vane → Vane API key, then press Load channels.
  4. 4. Post. Open a note, press Ctrl/Cmd+P and run Post note to Vane (or click the send icon in the left bar). Tick the channels, choose “As soon as possible” or a time, press Post.

Commands

CommandWhat it does
Post note to VaneOpens the post window with the whole note.
Post selection to VaneThe same, for the text you selected (only shows when something is selected).
Reload Vane channelsReads your channels again after you connect a new one.

What happens to your note

  • The properties block, comments (%%…%%), embeds and images are dropped. **bold**, headings and [[wikilinks]] lose their markers; web links are written out in full. #hashtags and line breaks stay.
  • You see the final text in the window and can change it. Both clean-up options can be switched off in the plugin settings.
  • The plugin does not attach images or video yet. For those use the editor on the Create tab.

Good to know

  • Your key stays on your server; the browser never sees it. Only Editors and Administrators can post, only Administrators can connect the key.
  • Live posting needs a plan with API access; a test key is always free. Posts made from WordPress count against your plan like any API post.

Make & Zapier

Post from your automations: a new row, a new article or a finished video turns into a scheduled post. Both use an API key from Vane; you add it once when you create the connection.

Before you start: get a key

Open API keys, create a key and under Used with choose Make or Zapier. Begin with a cpost_test_… key: requests are checked and answered like real ones, but nothing is posted or counted. Switch to a cpost_live_… key when it works (live keys need a plan with API access).

Make

  1. 1. Add the Vane app. The app is not in the public Make directory yet, so open the invite link and add it to your Make account. Then in a scenario press + and search for Vane.
  2. 2. Create the connection. Press Create a connection, paste your key and save. Make checks it right away.
  3. 3. Pick a module. For example Schedule a Post: fill in the text and the time, and choose channels from the list (it shows your channel names, so there are no ids to paste).
  4. 4. Run once. With a test key the result says TEST MODE and nothing is posted. Then swap in the live key.
ModuleWhat it does
Schedule a PostAction. Schedules a post, or sends it right away.
Get a PostAction. Reads one post and its status.
Cancel a PostAction. Removes a post that has not gone out yet.
List PostsSearch. Scheduled or recent posts.
List ChannelsSearch. The channels connected to Vane.

Zapier

  1. 1. Add the Vane app. The app is not in the public Zapier directory yet, so open the invite link and accept it. Then in a Zap choose Vane as the trigger or as the action app.
  2. 2. Sign in with your key. When Zapier asks to connect an account, paste your API key. Zapier tests it right away.
  3. 3. Pick what Vane does. Use Create Social Post as the action: text, channels (a list of your channel names), publish time and an optional image.
  4. 4. Test the Zap. A test key posts nothing. Then swap in the live key.
StepWhat it does
Create Social PostAction. Schedules a post to the channels you pick.
New Published PostInstant trigger. Fires the moment a post goes out.
Post FailedInstant trigger. Fires when a post could not be sent, so you can be told.

Good to know

  • Errors read like [402] message (quota_exceeded), so a scenario or Zap can react to the code.
  • Posts made from automations count against your plan like any API post.
  • Use a separate key for each tool. To cut one off, revoke that key under API keys; the others keep working.
  • Want something else? Any tool that can send an HTTP request works with the same key: see Developers.
