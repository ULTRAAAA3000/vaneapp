Admin password hash

Everything happens in this page, in your browser: the password is never sent anywhere.

1. Make the hash

Type the password you want for /admin (at least 12 characters). Copy the result into the Cloudflare secret ADMIN_PASSWORD_HASH, with no quotes and no spaces around it.

2. Check a password against a hash

Paste the value of ADMIN_PASSWORD_HASH exactly as you saved it, and the password you type on the sign-in page. It tells you whether they belong together, and what is wrong if not.
