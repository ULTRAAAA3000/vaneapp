## 1. Основная Philosophy, Headless Vision & Раздельная Архитектура

Vane — это сверхбыстрый, легкий (Cloudflare Edge) автопостинг, API-шлюз и движок управления контентом для соло-фаундеров, инди-хакеров, разработчиков, SMM-специалистов и видео-мейкеров.

### Ключевые отличия и структура продуктов:
1. **Раздельная продуктовая матрица:**
   * **Vane Post (Text Engine):** Движок текстово-графического кросс-постинга (`post.vaneapp.dev`).
   * **Vane Studio (Video Engine):** Независимый видео-дашборд и движок рендеринга/загрузки Shorts, Reels и TikTok (`studio.vaneapp.dev`).
2. **Без «Налога на каналы»:** Фиксированная ставка за подписку без доплат за количество подключенных аккаунтов.
3. **Instant Edge Publishing (0ms cold starts):** Выполнение задач секунда в секунду благодаря 300+ дата-центрам Cloudflare по всему миру.
4. **Headless & AI-Native First:** Нативная поддержка REST API, Make.com, Zapier, Custom GPT Actions, Claude MCP Server и плагина `Vane for WordPress`.

## 🔄 3. Кросс-Продукт Интеграция (Vane Studio ➔ Vane Post Link)

Хотя Vane Post и Vane Studio функционируют на независимых кодовых базах и дашбордах, между ними реализована **бесшовная экосистемная связка через API**:

1. **Cross-Post Prompt при загрузке видео:**
   * Когда пользователь в `Vane Studio` завершает настройку и отправку видео (на YouTube, TikTok или Reels), интерфейс показывает опциональный блок: **«Отправить анонс этого видео в социальные сети?»**.
2. **Механика работы под капотом:**
   * При согласии Vane Studio берет название видео, сгенерированное описание и ссылку на ролик.
   * Видео-дашборд через серверный запрос вызываeт эндпоинт Текстового API: `POST https://api.vaneapp.dev/v1/posts/create`.
   * Передаются авторизационные данные единого аккаунта пользователя (`cpost_live_...` или внутренний токен).
   * Пост мгновенно уходит в привязанные Telegram-каналы, X, LinkedIn или Bluesky пользователя без необходимости переходить в `post.vaneapp.dev`.

## 💳 6. Платежная Инфраструктура и Эквайринг

С учетом текущего возраста (16 лет) и локации (Украина) используется рабочая двухконтурная схема до перехода на европейский юридический контур:

└──────────────┬───────────────────────────────┬──────────────┘
│                               │
▼                               ▼

(Monobank Acquiring Int.)        (USDT / USDC Solana)
│                               │
▼                               ▼
┌─────────────────────────────┐ ┌─────────────────────────────┐
│ Monobank Acquiring API      │ │ Custom Cloudflare Worker    │

│ — Иностранные карты (USD/EUR│ │ — Solana / Polygon          │

│                              │

### 6.1. Контур А: Monobank Acquiring (International Mode)
* **Суть:** Включение поддержки международных Visa / Mastercard и Apple Pay / Google Pay в кабинете мерчанта Monobank.
* **Как работает для европейцев:** Покупатель из Германии или США вводит данные своей карты в EUR/USD или зажимает Apple Pay. Monobank списывает эквивалент в UAH по актуальному курсу, сам проводит трансграничную конвертацию и зачисляет деньги на украинский счет.
* **Мгновенный Webhook:** При успешном списании Monobank отправляет JSON-вебхук на Cloudflare Worker для активации подписки/генерации ключа `cpost_` или `cvid_`.

### 6.2. Контур Б: Crypto Checkout (USDT / USDC на Solana / Polygon)
* **Суть:** Прямая Web3-оплата для инди-хакеров, разработчиков и крипто-сообществ.
* **Как работает:**
  1. Юзер выбирает план (например, Pure Developer API за $5.99 или Vane Suite за $18.00).
  2. Frontend показывает QR-код с суммами и адресом Solana-кошелька Vane.
  3. Cloudflare Worker под капотом слушает Solana RPC-узел (через Helius/QuickNode).
  4. При обнаружении транзакции с нужной суммой Worker за **0.5 секунд** активирует подписку в D1.

### 6.3. Транзит в Европу (Перспектива: Австрия / 18 лет)
* При переезде в Клагенфурт и получении австрийского IBAN/ВНЖ за 15 минут активируется прямой аккаунт Stripe / Paddle.
* В коде бэкенда замена провайдера требует только обновления переменной окружения `PAYMENT_GATEWAY_KEY`.

## 🔑 7. API Key Scoping & Security Specification

Для изоляции доступов, безопасности и мгновенной валидации на Edge используется префиксная система API-ключей:

* **Text Post Engine Key:** `cpost_live_[16_char_hash]` (Доступ к текстово-графическим эндпоинтам Vane Post).
* **Video Engine Key:** `cvid_live_[16_char_hash]` (Доступ к видео-эндпоинтам Vane Studio и R2 Chunked Uploads).
* **Test Mode Keys:** `cpost_test_...` / `cvid_test_...` (Эмуляция ответов без списывания квот).
* **Security Standard:** Ключи генерируются через `crypto.getRandomValues()`, хешируются по алгоритму SHA-256 и сохраняются в D1.
