# Будущее

Идеи, которые решено не делать до запуска. Каждая записана так, чтобы к ней можно было вернуться без контекста разговора.
Возвращаемся после запуска, когда есть пользователи и данные.

| Идея | Файл | Вернуться, когда |
|---|---|---|
| Публичный профиль автора (`vaneapp.dev/@name`), без ленты, с блоком «Похожие авторы» | [public-page.md](public-page.md) | есть живые пользователи (20–30 активных авторов) и они просят «одну ссылку» |
| Cowork: отдельный план для команды (5 мест, согласование, роли) | [cowork.md](cowork.md) | после основного запуска; решить Suite и урезанный/расширенный Cowork, посчитать экономику |
| Способы оплаты по странам: Monobank для Украины, местная кнопка для Чехии, отдельные Apple Pay / Google Pay | [payments-by-country.md](payments-by-country.md) | оплата через ČSOB работает и приносит деньги; решено с бухгалтером, кто продавец при оплате Monobank |
