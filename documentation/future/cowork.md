# Cowork: отдельный план для команды (идея на будущее)

Статус: идея, отложена. Обсуждено 2026-11-03. Заменяет прежний черновик `../COWORK_AND_AGENCY_PLAN.md` (там Cowork был аддоном $4.99).
Принцип тот же: просто, понятно, проще конкурентов. Числа ниже предварительные, корректируем позже.

## Что решено
1. Cowork это **отдельный план, а не аддон**. Он про людей, а Suite про продукты: это разные оси, их не смешиваем.
2. Старт **после основного запуска**. Основной запуск, скорее всего, будет без видео (одобрения сетей занимают неизвестное время): Free, Developer API и Pro. Cowork, Studio, Suite и Analytics идут позже.
3. Cowork на старте **только с постами** («Pro на команду»). Видео добавится потом.
4. **Agency сливаем в Cowork**, отдельного плана Agency не будет.
5. **Места:** 5 включено (владелец + 4), дополнительное место $4.99, максимум 10.
6. **Цена:** от $35.99 в месяц. Не ставить равной цене Suite ($39.99): покупатель запутается.
7. **Общий пул на команду:** посты около 3 000 в месяц (у Pro 1 000 на одного). Числа потом скорректируем.
8. **Функции** (утверждены): см. ниже.

## Функции только для Cowork
Первая версия:
1. Роли `owner / editor / viewer`.
2. Согласование: черновик → «на проверке» → «одобрено» → запланировано (редактор не может запланировать без одобрения).
3. Согласование по ссылке без регистрации (для клиента или начальника): кнопки «Одобрить» и «Вернуть с комментарием».
4. Комментарии к черновикам и журнал правок (кто и что менял; действия в `logs` уже пишутся с `user_id`).
5. Общая библиотека медиа, сниппетов и хэштегов.

Следом: права по каналам (кому в какой канал можно публиковать), уведомления в Telegram или на почту («черновик ждёт проверки», «пост не ушёл»), общий календарь команды с цветом по автору и предупреждением о конфликте времени, еженедельный командный отчёт.

Кусочки бывшего Agency (клиентские пространства, white-label, отчёты клиентам, массовое планирование CSV): в $35.99 не помещаются. Записаны как возможное расширение Cowork позже, без отдельного плана.

## Что ещё в обсуждении (на решение)
**Как соотносятся Cowork, Suite, API, AI и аналитика. Два варианта:**
- **Урезанный (мой выбор).** Cowork = «Pro на команду». Analytics Pro, AI Pass, API и позже Video команда докупает теми же аддонами, что и одиночный пользователь. Плюсы: нет дублирования Suite, Cowork ничего не обещает без Studio, новых тарифов нет. Полный командный набор при этом: $35.99 + Video (плоско +$14.99?) + Analytics $4.99 + AI Pass $2.99 + API $4.99 ≈ $64.
- **Расширенный.** Cowork = «Suite на команду», всё включено, цена $75–90. Минус: нельзя запускать без Studio, цена пугает. Можно оставить как будущую ступень (Cowork Suite).

В урезанном варианте по числам: AI общий пул около 100–150 кредитов на всех плюс AI Pass; аналитика базовая как у Pro; API по аддону; ключ API один на команду.

**Suite $39.99 и сумма частей.** Pro $11.99 + Video $14.99 + Analytics $4.99 + AI Pass $2.99 = $34.96, Suite дороже. С полным API add-on ($4.99) сумма $39.95, то есть Suite равна частям без скидки (в Suite только 75 API-постов вместо 180). Значок «Best value» пока неверен. Решение: снизить цену Suite (к $29–35) или добавить ценности (например, 180 API-постов, больше AI-кредитов). **Не решено, решает владелец.**

## Проверка цены на живых данных
- 5 мест по $35.99 = $7.20 за человека при Pro $11.99. Цена Cowork равна трём Pro, четвёртое и пятое место бесплатные. К обычной цене Pro $14.99 скидка около 52 %.
- Окупается с трёх человек (при Pro $11.99: 3 × $11.99 = $35.97).
- 10 мест: $35.99 + 5 × $4.99 = $60.94 против $120 за десять Pro.
- Предварительно смотреть на $39.99–44.99, не равным Suite.

## Лестница тарифов (ориентир)
Free, Developer API, Pro Dashboard, Video Engine (Studio), Suite, Cowork + аддоны Analytics Pro, AI Pass, API add-on. Это около восьми позиций без выдуманных планов. На странице цен основные карточки показываем, остальное прячем в «Дополнения»: больше 4–5 карточек пугают покупателя.
