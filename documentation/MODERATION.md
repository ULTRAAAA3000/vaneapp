# Модерация контента

Что блокируется: мат (русский, украинский, английский, транслит) в постах и в названии/описании/тегах видео; картинки и видео 18+ и с сильным насилием.

## Как работает
- **Текст** — локальный список слов (`functions/api/lib/moderation.ts`), без внешних сервисов. Понимает «х у й», «х.у.й», латинские двойники букв. Сообщение пользователю не повторяет слово.
- **Картинки** — при загрузке (`/api/media/upload`), у обложек и у ссылок на чужие картинки в посте (скачиваются и проверяются).
- **Видео в Post** — браузер берёт 3 кадра (10 %, 50 %, 90 %) и отправляет вместе с файлом (поля `frame`). Сервер проверяет кадры. Видео без кадров не принимается; видео по ссылке с чужого сайта не принимается (его нельзя проверить, надо загрузить в Vane).
- **Видео в Studio** — проверяется кадр-превью, который браузер отправляет после загрузки. Если он не проходит, видео автоматически удаляется из библиотеки.
- Кадры — это проверка по выборке, а не просмотр всего видео: редкую вставку между кадрами можно пропустить.

## Что включить (необязательно, но точнее)
В Cloudflare → Workers & Pages → vaneapp → Settings → Variables and Secrets добавить секрет **`OPENAI_API_KEY`** (ключ с platform.openai.com; endpoint модерации бесплатный). Без него проверка идёт через Workers AI (`llama-3.2-11b-vision-instruct`), она менее точная.

Если провайдер временно недоступен, картинка пропускается (чтобы наш сбой не блокировал людей), ошибка пишется в логи.

`MODERATION_OFF=1` выключает всё (только для локальной разработки).

## Для API
`POST /api/media/upload` с видео: multipart, поле `file` + до 3 JPEG-кадров в полях `frame`. Ответ 422 с понятным текстом при нарушении. Ошибки текста: HTTP 422, `code: "profanity"`; медиа: `media_adult`, `media_violence`, `media_unchecked`.
