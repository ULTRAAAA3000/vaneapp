# Vane — AI Features, Capabilities & Tier Breakdown Specification

**Версия документа:** 1.0.0  
**Статус:** Утвержденная спецификация ИИ-модулей  
**Назначение:** Полный реестр всех искусственных интеллектов и утилит на базе Cloudflare Workers AI, их назначение, архитектура и распределение по тарифным сеткам Vane.

---

## 🧭 1. Общий обзор архитектуры ИИ в Vane

Все ИИ-функции платформы работают на инфраструктуре **Cloudflare Workers AI** (с использованием легковесных и быстрых моделей, таких как `@cf/meta/llama-3.1-8b-instruct`), что обеспечивает:
* **Нулевой холодный старт (0ms Cold Starts):** Запросы обрабатываются на Edge-серверах Cloudflare ближе к пользователю.
* **Минимальная себестоимость (COGS):** Себестоимость одной генерации составляет доли цента (~$0.00001), что гарантирует валовую маржу выше 99%.
* **Строгое разделение доступа:** Базовые утилиты для работы с текстом доступны абсолютно всем пользователям (включая Free Trial), в то время как глубокая генерация контента и реформатирование привязаны к **Vane AI Pass** (входит в Pro-тарифы) или тарифицируются в API.

---

## 🆓 2. Free AI Utilities (Доступно на всех тарифах и в Free Trial)

Эти инструменты созданы для снятия рутинной боли при оформлении постов и доступны каждому пользователю без ограничений по подписке.

### 1. Hashtag Generator (Генератор хештегов)
* **Назначение:** Анализирует текст поста и автоматически подбирает релевантные трендовые хештеги для соцсетей.
* **Где работает:** В визуальном редакторе дашборда и через API.
* **Стоимость для юзера:** Бесплатно (входит в базовый функционал).

### 2. Emoji Enhancer & Grammar Fix (Эмодзи-улучшайзер и орфография)
* **Назначение:** Исправляет опечатки, грамматические ошибки и органично расставляет эмодзи по тексту поста, сохраняя авторский стиль.
* **Где работает:** Кнопка «Make it clean» в редакторе.
* **Стоимость для юзера:** Бесплатно.

### 3. Char Limit Guard (Контроль лимитов символов)
* **Назначение:** Автоматически проверяет длину поста и предупреждает (или предлагает обрезку), если текст превышает лимиты выбранной сети (например, 300 символов для Bluesky или 280 для X).
* **Где работает:** Фоновая проверка в UI перед отправкой.
* **Стоимость для юзера:** Бесплатно.

## 💎 3. Vane AI Pass / Premium Features (Pro Dashboard & API Tier)

Глубокие генеративные функции, требующие больших вычислительных ресурсов LLM. Включены без лимитов (мягкий порог ~250 генераций/мес) в **Vane Post Pro** и **Vane Suite Bundle**, либо тарифицируются по **$0.09 / пост** в Pure Developer API Tier.

### 1. Smart Re-formatter (Умный кросс-платформенный реформатор)
* **Назначение:** Главная фишка кросс-постинга. Пользователь пишет один лонгрид (например, для Telegram), а ИИ на лету трансформирует его в:
  * Тред (цепочку постов) для X / Threads.
  * Структурированный деловой пост с буллетами для LinkedIn.
  * Короткий емкий снайпет со ссылкой для Bluesky и Mastodon.
* **Где работает:** В окне выбора каналов в дашборде и через эндпоинты API.

### 2. Full Post & Idea Generator (Генератор постов с нуля)
* **Назначение:** Помогает преодолеть «синдром чистого листа». Пользователь вводит короткую идею или тезис (например, *"Написал новый плагин для WordPress"*), а ИИ разворачивает её в полноценный готовый пост для выбранных соцсетей.
* **Контент-планы:** Генерация сетки постов на неделю вперед на основе сферы деятельности проекта.

### 3. Tone Fixer (Трансформатор тональности)
* **Назначение:** Меняет стиль написания текста в один клик. Доступные тона:
  * *Professional* (Строгий, для LinkedIn).
  * *Viral / Hook-driven* (Яркий, провокационный, для X и Telegram).
  * *Friendly* (Дружелюбный, мягкий).
  * *Tech / Indie Hacker* (Стиль Build in Public, технический).

### 4. Hook & CTA Generator (Генератор хуков и призывов)
* **Назначение:** Создает цепляющие первые предложения (Hook) для удержания внимания читателя и мощные Call-to-Action (CTA) в конце поста.

### 5. Video Script & Metadata Generator (Доступно в Vane Studio)
* **Назначение:** Генерация сценариев, хуков, описаний, авто-тегов и таймкодов для YouTube Shorts, TikTok, Reels и полноценных роликов на YouTube.
