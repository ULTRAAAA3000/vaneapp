Limits before you schedule

Each network counts differently: Bluesky by visible characters, Mastodon with links fixed at 23, Threads with emoji by size. Vane counts the same way, shows it next to every channel, and refuses to schedule a post a network would reject.

A preview for each network

The editor shows your post the way each network will draw it: a LinkedIn post, a Threads post, a Telegram message, a Bluesky post. Fix the text once, not after it is live.

Sign-ins that stay yours

Each network gets only the permission it needs to publish. Tokens are stored encrypted, and you can disconnect from Vane or from the network’s own settings at any time. How we protect them.
