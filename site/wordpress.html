WordPress plugin

Vane inside your WordPress admin.

A small Vane dashboard in the left menu: write a post, pick the channels, post now or pick a time, watch the queue and the history. Plus an automatic cross-post the moment you publish an article. No terminal, no code.

Download the plugin (.zip) Install in 2 minutes

Version 2.0 · works with WordPress 6.0+ and PHP 7.4+ · free; you need a Vane account and an API key

Write and post

  • Type a post, tick channels, see the character limit of each network as you type.
  • Add an image from your Media Library, or insert one of your latest articles with its link in one click.
  • Post in about a minute, or schedule a time.

Scheduled and history

  • See what is queued and cancel it before it goes out.
  • See what was sent, with a link to the live post, and why a post failed if it did.
  • Your plan and remaining posts are always in the header.

Cross-post articles

  • A “Vane Cross-Post” panel in the editor sidebar: channels, editable text, one send when you publish.
  • Fires once, when the article first goes live. Editing it later never posts again.
  • Works with scheduled articles and the classic editor.

Safe by design

  • Your key stays on your server; the browser never sees it.
  • Test keys try everything and post nothing.
  • Only Editors and Administrators can post; only Administrators can connect the key.

Install

From zero to your first post.

  1. 1

    Add the plugin

    Download the zip above. In WordPress go to Plugins → Add New → Upload Plugin, choose the file, press Install Now, then Activate. (Once the plugin is in the WordPress.org directory you can also search “Vane” there.)

  2. 2

    Get a key

    Open Vane, sign in (or create a free account), connect your channels, then go to API keys and create a key. Start with a cpost_test_… key: it tries everything and posts nothing.

  3. 3

    Connect

    In the WordPress menu open Vane, paste the key, press Connect. Your plan and channels appear.

  4. 4

    Post

    On the Write tab type something, tick a channel, press Post now. When you are happy, swap to a cpost_live_… key under Settings.

Live keys need a plan with API access; the pricing page has the details. Writing and testing with a test key is always free.

Questions

Good to know

What does the plugin send to Vane?

Only what you post: the text, the channel choices, an image address, and for articles the title, excerpt, link and featured image. Nothing is sent until you add a key and press Post or publish an article. Details are in the privacy policy.

How do I stop cross-posting articles?

Vane → Settings → untick “Cross-post new articles”. You can also switch it off for one article in the editor sidebar. The Write tab keeps working.

Can I remove it?

Yes. Press Disconnect under Vane → Settings, or just deactivate and delete the plugin: its settings are removed with it. Revoke the key in Vane to cut the access completely.

Something went wrong

The dashboard shows Vane’s reason in plain words (for example a full quota or a channel that needs reconnecting). Still stuck? Tell us.
